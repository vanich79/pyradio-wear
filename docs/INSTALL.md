# Установка на часы

Инструкция для тех, кто не занимается программированием. Ничего собирать не нужно —
только скачать готовый файл и передать его на часы.

**[⬇ Скачать PyRadio для часов](https://github.com/vanich79/pyradio-wear/releases/latest)** —
на странице релиза возьмите файл `pyradio-wear-0.2.1.apk`.

---

## Сразу о главном

> [!warning] Кабелем не получится
> У часов на Wear OS — включая TicWatch Atlas — нет разъёма USB. То, чем они
> заряжаются, это только питание, данные по нему не ходят. Поэтому установка
> возможна **только по воздуху**, через Wi-Fi.

> [!note] Почему так сложно
> Приложения нет в Google Play, а всё, что ставится мимо магазина, Android
> пропускает только через **режим разработчика**. Это не наша прихоть и обойти
> это нельзя. Зато делается один раз.

Выберите способ:

| | Что нужно | Кому подойдёт |
|---|---|---|
| **Способ 1** | Только телефон | Если компьютера под рукой нет |
| **Способ 2** | Компьютер | Если телефон Android недоступен или первый способ не пошёл |

---

## Шаг 0. Разбудить режим разработчика на часах

Это нужно для обоих способов.

1. На часах откройте **Настройки → Система → О часах → Версии**.
2. Найдите строку **«Номер сборки»** и нажмите на неё **семь раз подряд**.
   Появится надпись «Теперь вы разработчик».
3. Вернитесь в **Настройки → Для разработчиков** и включите два переключателя:
   - **Отладка по ADB**
   - **Отладка по Wi-Fi**
4. Под вторым переключателем часы напишут адрес вида `192.168.1.105:40679`.
   Он понадобится дальше. **Запишите его.**

> [!important] Часы и телефон (или компьютер) должны быть в одной сети Wi-Fi
> Если часы подключены к интернету через телефон по Bluetooth, а не по Wi-Fi,
> установка не пройдёт. Подключите часы к домашнему Wi-Fi:
> **Настройки → Подключения → Wi-Fi**.

---

## Способ 1. С телефона, без компьютера

Понадобится телефон на Android и любое приложение для установки на часы по ADB.
Такие приложения есть в Google Play — например, **Wear Installer 2**. Это сторонняя
программа, не наша; работает она так же, как описано ниже, просто прячет команды
за кнопками.

1. Скачайте на телефон файл `pyradio-wear-0.2.1.apk`
   [со страницы релиза](https://github.com/vanich79/pyradio-wear/releases/latest).
2. Установите на телефон приложение для установки на часы.
3. Откройте его и введите адрес часов из шага 0 (`192.168.1.105:40679`).
4. **На часах появится запрос «Разрешить отладку?»** — нажмите «Всегда разрешать
   с этого компьютера» и подтвердите. Этот запрос легко пропустить: он висит
   несколько секунд, а без него ничего не произойдёт.
5. Выберите скачанный файл и нажмите установить.

Через полминуты приложение появится в списке приложений на часах.

---

## Способ 2. С компьютера

1. Скачайте **Android SDK Platform Tools** — это набор из нескольких файлов,
   ставить ничего не надо, достаточно распаковать:
   https://developer.android.com/tools/releases/platform-tools
2. Распакуйте архив, например, в `C:\platform-tools`.
3. Скачайте туда же файл `pyradio-wear-0.2.1.apk`
   [со страницы релиза](https://github.com/vanich79/pyradio-wear/releases/latest).
4. Откройте в этой папке командную строку: нажмите на пустое место в папке правой
   кнопкой мыши при зажатом **Shift** → «Открыть окно PowerShell здесь».
5. Введите две команды, подставив свой адрес из шага 0:

```powershell
.\adb.exe connect 192.168.1.105:40679
.\adb.exe install pyradio-wear-0.2.1.apk
```

6. **После первой команды посмотрите на часы** — там появится запрос «Разрешить
   отладку?». Нажмите «Всегда разрешать» и повторите первую команду.
7. Ответ `Success` означает, что приложение установлено.

## После установки

Приложение работает само по себе: список станций, воспроизведение, громкость.
Но две вещи стоит настроить руками — они того стоят.

### Плитка: включить радио одним касанием

Свайп вправо с циферблата, долистать до конца, нажать `+`, выбрать **«Радио»**.

Теперь свайп вправо — и последняя станция играет с одного нажатия, не открывая
приложение.

### Комплик: видеть на циферблате, что играет

Долгое нажатие на циферблате → **Настроить** → выбрать место на циферблате →
пролистать список до **PyRadio → «Что играет»**.

Прочерк означает, что радио молчит; жанр станции — что играет. Нажатие включает
последнюю станцию.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| `failed to connect` / `device offline` | Часы закрыли порт отладки. Выключите и снова включите «Отладку по Wi-Fi» — **адрес и порт поменяются**, возьмите новые |
| `unauthorized` | На часах не подтверждён запрос отладки. Посмотрите на экран часов и нажмите «Всегда разрешать» |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | На часах стоит версия, собранная другим ключом. Удалите старое приложение с часов и поставьте заново |
| Часы вообще не находятся | Часы и компьютер должны быть в одной сети Wi-Fi. Проверьте на часах: **Настройки → Подключения → Wi-Fi** |
| Станция «не отвечает» | Это не поломка установки: часть станций в плейлисте закрылись. Выберите другую |

---

## Обновление

Новую версию ставят точно так же — поверх старой, ничего не удаляя. Избранное и
последняя станция сохранятся.

Единственное условие: обновление должно быть подписано тем же ключом, что и
установленная версия. Файлы со страницы релизов подписаны одинаково, так что
между ними всё обновляется нормально.
